# AI 学习导师系统 · 本地工作区

> 你是学习者,`Hermes` 是你的长期 AI 学习导师。本目录保存你全部学习数据;**网站只是可视化面板,教学与批改由 Hermes 完成**。

## 一、这是什么

一个跑在本机的「AI 学习导师」系统:

- **首次采访**:Hermes 先认识你(目标、背景、时间),生成专属 Roadmap;
- **每日教学闭环**:每天按计划讲 → 练 → 批改 → 总结 → 调整未来几天;
- **动态 Roadmap**:根据真实掌握情况滚动调整,不机械执行旧计划;
- **本地 Dashboard**:`http://127.0.0.1:8321` 查看路线、打卡、掌握度、错题、周报;
- **定时任务**:每日提醒、未完成提醒、每周复盘、数据维护;
- **数据全在本机**:`C:\Users\DELL\Projects\AI-Study\`,重启不丢。

## 二、目录结构

```
Projects/AI-Study/

│   ├── checkins.json        # 每日打卡

│   └── roadmap-changelog.md # 调整记录(改了什么、为什么)
├── 每日记录/YYYY-MM-DD.md    # 当天教学、练习、批改
├── 错题本/按知识主题归档.md   # 由 mistakes.json 自动生成

    ├── server.py            # 本地服务(127.0.0.1:8321)
    └── www/index.html       # 前端面板
```

## 三、快速开始

1. **完成首次采访**:对 Hermes 说「**开始学习**」或「**我想学 AI**」,回答几个问题(10 分钟内),确认目标后生成 Roadmap;
2. **每天学习**:对 Hermes 说「**今天学什么**」/「**继续昨天**」/「**开始**」;学完说「**今天到这**」,导师自动打卡、总结、调整计划;
3. **看面板**:双击 `启动Dashboard.bat`,浏览器打开 `http://127.0.0.1:8321`;
4. **查进度**:说「**我学到哪了**」;每周说「**复盘**」(或等周日自动周报)。

常用口令(自然语言即可,无需记命令):
`今天学什么` `继续昨天` `今天到这` `复盘` `我学到哪了` `换目标` `重置学习档案`

## 四、Dashboard

| 项目 | 说明 |
|---|---|
| 启动 | `python Dashboard/server.py --port 8321`(或双击 `启动Dashboard.bat`) |
| 访问 | `http://127.0.0.1:8321`(只监听本机,不暴露公网) |
| 停止 | 关闭窗口 / `Ctrl+C` |
| 数据 | 页面每次刷新都从 `dashboard-data.json` 重新生成,打卡/标记任务直接写回同一套本地数据,Hermes 下次会话即可读到 |
| 异常 | 服务未启动或数据损坏时,页面顶部会显示明确提示 |

## 五、定时任务(Hermes Cron)

| 任务 | 时间 | 内容 |
|---|---|---|
| 每日开课提醒 | 每天 20:00 | 今日主题 + 预计时长(未建档时提醒先采访) |
| 当日未完成提醒 | 每天 21:30 | 温和询问继续 / 跳过(不责备、不伪造记录) |
| 每周复盘 | 周日 19:00 | 周报:进展、错题、Roadmap 变化、学习模式识别 |
| 数据维护 | 每天 00:05 | 校验并刷新展示数据,异常时告警 |

- **查看/暂停/删除**:对 Hermes 说「列出定时任务」,或 `hermes cron list`;暂停用 `hermes cron pause <id>`。
- **改提醒时间**:对 Hermes 说「把学习提醒改到 21:00」。
- **注意**:当前桌面会话无主动推送通道,提醒会保存在 Hermes 的 cron 运行记录里;最可靠的方式是每天固定时间打开 Hermes 说「今天学什么」。若以后接入 Telegram/Discord 等网关,可改为主动推送。

## 六、备份与恢复

- **自动备份**:所有 JSON 更新前自动保留最近 5 份 `.bak`(`状态数据/*.bak`),单个文件写坏可手工恢复。
- **手动备份**:复制整个 `Projects/AI-Study/` 目录即可(纯本地文件)。
- **恢复**:把备份目录覆盖回原位;运行 `python Dashboard/study_lib.py validate` 校验,再 `regen` 刷新面板。
- **建议**:每周备份一次(可让 Hermes 定期帮你压缩归档)。

## 七、修改目标 / 重置 / 增加新主题

- **换目标**(保留历史):对 Hermes 说「**换目标**」→ 重新确认目标 → 生成新周期 Roadmap,旧记录保留;
- **重置整个学习档案**:说「**重置学习档案**」→ 确认后清空学习数据,重新采访;
- **新增另一个学习主题**:说「**我想再学 XX**」→ Hermes 会在 `Projects/` 下新建同级 Project,不混入本套数据。

## 八、卸载

1. 删除定时任务:`hermes cron list` → `hermes cron remove <id>`(共 4 个);
2. 删除 Skill:对 Hermes 说「删除 ai-learning-mentor 技能」;
3. 删除本目录:`rm -rf "C:\Users\DELL\Projects\AI-Study"`(或手动删除);
4. 可选:恢复 `SOUL.md` 默认人格(备份在别处时)。学习数据删除前请先备份。

## 九、已知限制

- 桌面会话无法主动推送提醒,提醒保存在 cron 记录中(见第五节);
- 本机网络无法访问 github.com / OpenAI 文档 / HuggingFace,部分资源标注「待核实」,联网环境可让 Hermes 重新核实;
- 网站不做 AI 对话与批改(按设计),待验证的学习模式需在 Hermes 对话中确认;
- 定时任务在 Hermes 运行时才会触发(Hermes 未运行则顺延到下次启动检查)。

## 十、数据安全边界

- 所有学习数据仅存本机;没有任何云端同步;
- 网站仅监听 `127.0.0.1`,不对外暴露;
- 涉及最新 AI 产品/API/价格等信息,导师会核实来源或标注「待核实」,不编造。
