# 项目资料数据库(LAN 局域网共享系统)

> 一个部署在公司局域网内的项目资料管理系统:按「项目 → BOM 物料 → 资料文件」三层结构组织,同事在浏览器里即可浏览、搜索、上传、下载设备资料,无需安装任何客户端软件。

---

## 一、系统能做什么

### 核心功能一览

| 功能 | 说明 |
|---|---|
| 📁 项目列表 | 登录后首页按编号显示全部项目,双击进入 |
| 📋 BOM 清单 | 每个项目一份 Excel BOM,自动解析成物料表格 |
| 🔍 物料资料 | 点击物料号进入资料页,查看图纸/文档/说明书 |
| ⬇ 下载资料 | 登录用户可下载物料全部资料 |
| ⬆ 上传资料 | 登录用户可上传资料到指定物料,版本号自动递增 |
| ➕ 新建项目 | 管理员/一级用户可创建新项目(编码+名称) |
| ➕ 添加物料 | 管理员/一级用户可在 BOM 中添加物料(含规格/制造商) |
| ✏ 编辑管理 | 管理员可修改项目名称、物料号、规格、制造商、版本号 |
| 🔐 三级权限 | 管理员/一级用户/二级用户,权限分明 |
| 📝 注册审批 | 同事可在线申请账号,管理员审批后生效 |
| 📊 操作日志 | 管理后台记录每个人的上传/下载行为 |

### 权限模型

| 能力 | 管理员(admin) | 一级用户 | 二级用户 |
|---|---|---|---|
| 浏览项目 / BOM / 物料资料 | ✅ | ✅ | ✅ |
| 上传 / 下载资料 | ✅ | ✅ | ❌ |
| 新建项目 / 添加物料 | ✅ | ✅ | ❌ |
| 编辑项目 / 物料信息 | ✅ | ❌ | ❌ |
| 管理后台(审批/账号/日志) | ✅ | ❌ | ❌ |

> 新注册的账号默认为**二级用户**(只读);需要上传下载权限时,由管理员在「管理后台 → 账号管理」中将其设为**一级用户**。

## 二、系统架构

```
浏览器(同事电脑)
    │  HTTP (局域网)
    ▼
server.py  ── 网页服务(Python 标准库,零框架)
    │
    ├── auth.json          账号与权限(管理员/一级/二级)
    ├── activity.json      操作日志(上传/下载记录)
    │
    ▼
D:\物料清单\               数据根目录
    ├── projects.json      项目索引
    ├── HY2026062301-浙江海港...项目\      项目文件夹(编码命名)
    │     ├── 总BOM清单.xlsx              项目 BOM(Excel)
    │     └── 物料资料\
    │           ├── 8S131100AA-总进线智能电表\   物料文件夹(物料号-名称)
    │           │     ├── 图纸\安装尺寸图.pdf
    │           │     └── 技术文档\使用说明书.docx
    │           └── ...
```

### 技术特点

- **零依赖**:仅用 Python 标准库实现网页服务,无需安装任何框架
- **唯一第三方库**:`openpyxl`(用于读写 Excel BOM)
- **数据即文件**:项目、物料、资料全部以真实文件夹/文件形式存储,网页只是它的"可视化窗口"—— 直接把文件拖进对应文件夹,网页立刻可见
- **兼容物料号命名**:自动识别如 `8Sxxxxxxxx` 和 `8Sxxxxxxxx-物料名称` 两种物料文件夹命名

## 三、使用说明

### 1. 访问地址

| 位置 | 地址 |
|---|---|
| 服务器本机 | `http://localhost:8000` |
| 局域网同事 | `http://192.168.1.110:8000` |

### 2. 首次使用流程

1. **登录**:输入账号密码(首次使用需先注册申请)
2. **申请账号**:登录页点「申请注册」→ 填账号/密码/姓名/部门 → 提交,等待管理员审批
3. **管理员审批**:admin 登录 → 右上角「管理后台」→ 待审批申请 → 同意/拒绝
4. **浏览资料**:首页双击项目 → 查看 BOM 清单 → 点击物料号 → 查看/下载/上传资料

### 3. 管理员日常操作

- **新建项目**:首页点「➕ 新建项目」→ 填编码+名称
- **上传 BOM**:项目页点「上传/更新 BOM Excel」(支持 .xlsx)
- **添加物料**:项目页点「➕ 添加物料」→ 填物料号/名称/规格/制造商
- **编辑信息**:项目页「✏ 编辑」按钮可改项目名;BOM 每行「✏ 编辑」可改物料号/名称/规格/制造商/版本号(改物料号时资料文件夹自动同步改名)
- **账号管理**:管理后台 → 账号管理 → 改密码 / 设一级/二级 / 删除账号

### 4. 版本号规则

- 每个物料默认版本号 **A00**
- 每上传一次资料,该物料版本号自动 +1:`A00 → A01 → A02 ...`
- 管理员也可手动修改版本号

## 四、部署信息

### 服务启动

```bash
cd "C:\Users\用户名称\Projects\AI-Study\共享服务"
"C:\Users\DELL\AppData\Local\Programs\Python\Python314\python.exe" server.py
```

> ⚠️ 必须用系统 Python 3.14 启动(它装有 openpyxl)。

### 防火墙放行(已完成)

- 端口 `8000` 已添加 Windows 防火墙入站规则(规则名「物料共享8000」)
- 若同事无法访问,检查防火墙规则是否仍在

### 浏览器代理注意事项

- 公司浏览器若配置了 **Privoxy 代理**,访问局域网地址时需添加代理例外:
  - Chrome/Edge → 设置 → 系统 → 打开代理设置 → 例外列表添加:
    `localhost;192.168.1.110`
- 或服务器本机直接用 `http://localhost:8000` 访问

## 五、数据文件清单

| 文件/目录 | 作用 | 备注 |
|---|---|---|
| `共享服务\server.py` | 网页服务主程序 | 唯一需要运行的代码 |

## 六、已知限制与规划

| 限制 | 说明 | 后续方案 |
|---|---|---|
| 服务不自动启动 | 电脑重启后需手动启动服务 | 配置开机自启 |
| Excel 文件占用 | 若用 WPS/Excel 打开 BOM 文件,网页无法修改它 | 迁移到数据库(SQLite) |
| 密码明文存储 | 密码以明文存在 auth.json | 学习加密存储 |
| 单机部署 | 服务运行在一台电脑,关机即不可用 | 部署到常开机服务器 |
